# DOMO — магазин бытовой техники

Автор: Шевченко Михаил, ДонГУ, группа ИВТ-5, 3 курс.

## Страницы по PSD
- Index.psd → dist/index.html — главная, категории, 8 товаров подборки, промоблок.
- Product.psd → dist/catalog.html — 12 позиций, фильтры категории, серии и цены; сортировка и пагинация.
- Single Page.psd → dist/single.html — карточка выбранного товара; у основной микроволновой печи 2 ракурса, выбор комплектации и количества.
- Shopping Cart.psd → dist/cart.html — изменение количества, удаление, промокод DOMO10, самовывоз или курьер.
- Checkout.psd → dist/checkout.html — контакты, доставка, состав заказа, подтверждение и скачивание состава.
- dist/information.html — сведения о доставке, данных, проекте, авторах фотографий и лицензиях.
- dist/404.html — вспомогательная страница ошибки.

Написано вручную на HTML5, CSS и JavaScript. Конструкторы и CSS-фреймворки не использованы. Структура и розовые акценты исходных PSD сохранены.

## Основные требования
Семантические header, main, nav, article, section, aside, footer, details, summary, output и dialog. Поля связаны с label, группы полей — с fieldset/legend. HTML5-валидация required, type=email/tel/number, min/max, minlength/maxlength, pattern; CSS-состояния полей; дополнительные проверки пробелов и цифр телефона.

Изображения плавно увеличиваются при наведении. Логотип и кнопка наверх поворачиваются на 360°, иконки возврата и удаления — на 180°. Применены transition, ease, cubic-bezier. Учтён prefers-reduced-motion.

Корзина хранится отдельно от варианта MOBI, в ключе domo-cart-v1. Поиск работает через форму шапки. Серии «Практик», «Комфорт», «Премиум», названия позиций, цены и условия — учебные. Фотографии иллюстрируют категории; некоторые используются для разных учебных серий. Реальные характеристики, наличие и коммерческие предложения не заявляются.

Настоящие заказы, платежи и передача контактов не выполняются. Файл заказа содержит только товары и суммы. Контактные данные не сохраняются. Для реального интернет-магазина потребуется сервер и реальные условия продавца.

## Исключённые части по запросу
Не включены HTML-письмо, рассылка и форма подписки. Не выполнялись отдельная SEO-часть, размещение на хостинге и Lighthouse-аудит. Обычные title, description, lang, кодировка и viewport оставлены как базовая разметка страниц.

## Проверки
Все 7 HTML-файлов прошли Nu HTML Checker без ошибок. Исходные ответы находятся в reports/nu-*.json. Проверены ссылки на локальные файлы и синтаксис JavaScript.

Во встроенном Chromium проверены все 6 основных страниц при ширинах 320, 768, 1000 и 1280 px: горизонтального переполнения документа нет. Матрица — reports/responsive.json.

Проверены фильтры, сортировка, галерея, добавление комплекта с набором ухода, сохранение количества после перезагрузки, промокод, доставка, обязательные поля и подтверждение заказа. Контрольный расчёт: (14 990 + 990) × 2 − 3 196 + 490 = 29 254 ₽. В проверенных сценариях ошибок в консоли нет. Сводка — reports/checks.json.

Проверка Microsoft Edge не завершена: система управления приложениями остановилась, поскольку не смогла достоверно определить текущий URL браузера. Результаты для Edge, Firefox и Safari не заявляются.

Источники и условия использования фотографий указаны на странице информации. Шрифт Lato — SIL OFL, лицензия в assets/Lato-OFL.txt.
